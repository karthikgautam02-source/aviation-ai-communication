Aviation AI Communication
AI-assisted passenger communication workflow for flight disruptions, combining prompt engineering, source verification and human review.
Business Problem
Airline service teams must communicate changing flight information clearly across channels. Incorrect timings, unsupported benefit claims and inconsistent messages can create passenger confusion.
This project explores a structured approach to drafting, checking and updating communications using fictional flight scenarios.
Key Features
Passenger emails, announcements, SMS and service desk responses.
Comparison of six prompting strategies.
Source-based checks for factual errors and unsupported claims.
Communication updates following revised operational timings.
English–Hindi consistency verification.
Reusable email prompt tested on a separate flight scenario.
Workflow
Establish flight facts, policy and information gaps.
Draft messages using structured prompts.
Evaluate accuracy, completeness, clarity and tone.
Correct unsupported claims and adapt messages for each audience.
Apply updated timings across communications.
Verify translations and test template reuse.
Verification Scenarios
Scenario
Required check
SB204: 2:00 PM scheduled, 4:30 PM expected departure
Calculate the 2-hour-30-minute delay and assess fictional voucher eligibility
SB204: expected departure updated to 5:15 PM
Replace earlier estimates and use the revised 4:15 PM passenger update
Unconfirmed gate, refund or hotel details
Flag missing information without inventing an answer
Guaranteed departure wording
Preserve the distinction between an estimate and a guarantee
SB310: 10:00 AM scheduled, 11:15 AM expected departure
Confirm the delay falls below the supplied two-hour voucher threshold

Deliverables
Documented prompts, outputs and manual checks.
Reviewed passenger communication pack.
Source-based evaluation and correction tables.
English–Hindi email pair.
Reusable prompt template with a separate flight test.
Tools and Skills
Tools: ChatGPT or Gemini, Microsoft Word, GitHub.
Skills: Prompt engineering, passenger communication, factual verification, audience adaptation, prompt chaining, multilingual review and template design.
Responsible AI Use
AI assists with drafting, evaluation and translation. The contributor independently checks source facts, records corrections and reviews final outputs.
This project uses fictional flight information and policies. It is not connected to live airline systems, and no messages are sent to actual passengers.
